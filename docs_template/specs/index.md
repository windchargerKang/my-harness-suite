# 系统规格

> 本目录存放系统的技术规格定义，作为设计和实现的基准参考。

## 目录结构

```
specs/
├── index.md          # 本文件 - 规格索引
├── api/              # API 规格（可选）
├── domain/           # 领域模型规格（可选）
└── integration/      # 集成规格（可选）
```

## 规格分类

### API 规格

记录系统对外暴露的接口定义，包括：

- 接口名称和用途
- 请求/响应结构
- 错误码定义
- 版本变更历史

### 领域模型规格

记录核心业务对象的定义，包括：

- 实体和值对象
- 业务规则
- 状态机定义

### 集成规格

记录系统间集成的定义，包括：

- 第三方服务集成
- 消息队列规范
- 事件定义

## 维护原则

1. **规格先于实现**：新功能先写规格，再实现
2. **规格追踪**：实现必须符合规格，变更必须更新规格
3. **版本管理**：规格变更需要记录历史
