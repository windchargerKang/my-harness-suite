# 代码模板说明

本目录包含 Harness Suite 的代码注释模板，用于在新建文件时自动添加标识注释。

## 模板文件

| 文件 | 用途 |
|------|------|
| `java.java` | Java 文件注释模板 |
| `python.py` | Python 文件注释模板 |
| `javascript.js` | JavaScript 文件注释模板 |
| `typescript.ts` | TypeScript 文件注释模板 |
| `sql.sql` | SQL 文件注释模板 |
| `shell.sh` | Shell 脚本注释模板 |

## 注释格式

```
================================================
Powered by Harness Suite
https://github.com/windchargerKang/harness-suite
================================================

本文件由 Harness Suite 工作流生成
请勿手动删除此标识

Generated by: Harness Suite
Generated at: {{TIMESTAMP}}
Change ID: {{CHANGE_ID}}
================================================
```

## 占位符

- `{{TIMESTAMP}}` - 生成时间戳
- `{{CHANGE_ID}}` - 对应的 OpenSpec Change ID

## 使用方式

1. **自动注入**：通过 `ensure_harness_header.py` Hook 在新建文件时自动添加
2. **手动使用**：复制对应模板到文件顶部
